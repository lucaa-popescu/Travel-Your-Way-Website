Proiect laborator

Pentru componenta de proiect a cursului, fiecare student trebuie să dezvolte un website[cite: 2]. Proiectul va fi realizat individual și va avea două părți[cite: 2]:

  1. HTML + CSS + responsive (predare și evaluare în timpul laboratorului 7, săptămâna 8)[cite: 2]
  2. JavaScript (predare și evaluare la ultimul laborator)[cite: 2]

Veți putea alege tema website-ului, dar va trebui să respectați o listă de cerințe generale[cite: 2].

Exemple de temă pentru proiect:

  • website personal[cite: 2]
  • website de prezentare a unei cărți, unui autor, unui joc, unei formații, unui regizor, unui actor sau unui film etc.[cite: 2]
  • blog personal, de călătorii, culinar etc.[cite: 2]
  • website cu conținut educațional (tutoriale, exploratory explanations, exerciții interactive scrise în JavaScript)[cite: 2]
  • website de prezentare a unei librării, biblioteci, muzeu, galerii de artă etc.[cite: 2]
  • website de prezentare a unui obiectiv turistic[cite: 2]
  • website comercial[cite: 2]
  • un joc mic, un proiect de artă multimedia[cite: 2]

Vă puteți consulta cu profesorul de laborator pentru alegerea temei. Vă vom arăta exemple ;-)[cite: 2]

Vă încurajăm să alegeți o temă care vă place, oricât de năstrușnică ar putea părea[cite: 2].

Punctajul pentru proiect (20 puncte)[cite: 2]:

  • HTML + CSS + responsive: 8 puncte[cite: 2]
  • JavaScript: 12 puncte[cite: 2]

Cerințe generale minimale pentru partea 1 (HTML + CSS)[cite: 2]:

  • fișiere separate pentru HTML și CSS[cite: 2]
  • conținutul site-ului trebuie să aibă sens (nu îl umpleți cu Lorem ipsum)[cite: 2]
  • nu este acceptată folosirea de frameworkuri și biblioteci[cite: 2]

HTML:

  • trecerea testelor de validare HTML http://validator.w3.org/[cite: 2]
  • folosirea tagurilor semantice prezentate la curs/laborator[cite: 2]

CSS:

  • trecerea testelor de validare CSS https://jigsaw.w3.org/css-validator/[cite: 2]
  • site-ul trebuie să fie responsive (media query, unități relative, tipuri de display)[cite: 2]
  • folosirea selectorilor CSS de bază (după id, clasă, tag, elementContinut, elementCopil, al n-lea copil de tipul unui tag :nth-of-type)[cite: 2]
  • specificarea proprietăților: width, height, color, background, font-size, border, padding, margin, display etc.[cite: 2]
  • folosirea coloanelor pentru layoutul a cel puțin unei pagini; realizarea layoutului fără tabele (folosind flex și grid)[cite: 2]
  • site-ul trebuie să conțină un menu drop-down (sau altfel expandabil) realizat cu CSS[cite: 2]
  • site-ul trebuie să conțină o tranziție care implică schimbarea mai multor proprietăți la intervale diferite de timp[cite: 2]
  • site-ul trebuie să conțină o animație care să modifice mai multe proprietăți ale aceluiași element[cite: 2]
  • ! bonus point ! pentru generarea conținutului folosind :after, :before (dar să aibă sens; fiți creativi)[cite: 2]

Cerințe generale minimale pentru partea 2 (JavaScript + ajax + misc)[cite: 2]:

A. JavaScript

  • fișier separat pentru codul JavaScript[cite: 2]
  • modificarea stilului unui element sau al unui grup de elemente[cite: 2]
  • manipularea DOM-ului (selectare după id, tag, clasă, folosind selectori CSS)[cite: 2]
  • crearea și stergerea de elemente HTML[cite: 2]
  • folosirea și modificarea evenimentelor generate de mouse si tastatură[cite: 2]
  • modificare de proprietăți[cite: 2]
  • inputuri funcționale (de exemplu: input de tip text/range/number/radio/checkbox, select, textarea)[cite: 2]
  • folosirea setTimeout sau setInterval[cite: 2]
  • folosirea localStorage (să se pastreze în localStorage o colecție de elemente)[cite: 2]
  • folosirea a cel puțin unei metode din clasele: Math, Array, String, Date[cite: 2]
  • schimbarea aleatoare a valorilor unei proprietăți (de exemplu: culoare, dimensiuni, poziție)[cite: 2]
  • folosirea proprietăților classList, target sau currentTarget[cite: 2]
  • folosirea metodelor getComputedStyle, stopPropagation[cite: 2]
  • validarea datelor dintr-un formular folosind expresii regulate[cite: 2]

B. AJAX

  • cereri Ajax cu preluare date dintr-un fișier json[cite: 2]
  • sesiuni: e.g. login/logout (folosind Storage / fișier json)[cite: 2]

Pe lângă implementarea acestor cerințe minimale (a căror rezolvare corectă nu garantează punctajul maxim), includeți în proiect și tratarea altor probleme (la alegere) precum cea a accesibilității, internaționalizării (traducere, caractere speciale etc.), folosirii canvas/svg etc[cite: 2].

Cerințele pot fi modificate și/sau completate de fiecare profesor de laborator[cite: 2].
